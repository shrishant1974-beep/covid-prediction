# Strikes E-Commerce Website

Premium e-commerce website built with HTML, CSS, and JavaScript.

## Features
- Responsive design with modern glassmorphism UI
- Product filtering and search
- Shopping cart with localStorage persistence
- Product modals
- Checkout form
- Animated effects and gradients

## Demo
Open `index.html` in your browser to view the live site.

## Quick Start
1. Clone the repo
2. Open `index.html` in browser
3. No build required!
